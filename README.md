# Grading-Calculator-for-Universities
A simple Python-based grading calculator that converts numerical scores (0–100) into letter grades (A–F) or Pass/Fail results depending on the course assessment type.

Features

Supports differentiated (A–F) and non-differentiated (Pass/Fail) grading systems.

Validates scores between 0 and 100.

Handles non-numerical inputs.

Uses Python conditional statements and exception handling.

Technologies

Python

How to Run

1)Download the grade_calculator.py file.

2)Run it using Python.

3)Enter your score and course type (d/n).

4)View your grade.
